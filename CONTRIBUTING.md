# Contribuciones

¡Gracias por tu interés en contribuir a Camiglobo!

## Cómo Contribuir

### 1. Fork el Repositorio
```bash
git clone https://github.com/tu-usuario/camiglobo.git
cd camiglobo
```

### 2. Crear una Rama
```bash
git checkout -b feature/tu-feature
# o para bugfix
git checkout -b bugfix/tu-bugfix
```

### 3. Hacer Cambios
- Mantener el código limpio y comentado
- Seguir la estructura de carpetas existente
- Validar entradas y sanitizar outputs (seguridad)

### 4. Commit y Push
```bash
git add .
git commit -m "feat: descripción clara de cambios"
git push origin feature/tu-feature
```

### 5. Abrir Pull Request
- Ve a GitHub y abre un PR contra `main`
- Describe qué cambios hiciste y por qué
- Espera revisión

## Estándares de Código

### PHP
- PHP 7.4+
- PSR-12 compliant cuando sea posible
- Comentarios en código complejo
- Validación en todos los inputs

### JavaScript
- ES6+
- Nombres de variables claros
- Sin console.log innecesarios

### CSS
- Mobile-first
- Reutilizar clases existentes
- Comentarios para estilos complejos

## Reporte de Bugs

Si encuentras un bug:
1. Verifica que no esté reportado ya
2. Crea un [Issue](https://github.com/juancasano/camiglobo/issues) con:
   - Descripción clara del problema
   - Pasos para reproducirlo
   - Resultado esperado vs. actual
   - Screenshots si aplica

Para preguntas generales, abre un [Discussion](https://github.com/juancasano/camiglobo/discussions).
